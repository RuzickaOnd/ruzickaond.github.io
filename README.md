# ruzickaond.github.io

GitHub Pages user site. Its only job is to serve `app-ads.txt` at the domain root
(`https://ruzickaond.github.io/app-ads.txt`), where AdMob looks for it for every app whose Play listing
website is on `ruzickaond.github.io` (Luxel: `/luxel-web/`, ClockOut: `/clockout-app-web/`).

Publisher ID comes from AdMob → Apps → View all apps → app-ads.txt.
One line per ad network; all apps of the same AdMob account share the line.
